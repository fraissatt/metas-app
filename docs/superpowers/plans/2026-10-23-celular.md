# Phone Adjustments Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (the user chose native execution). Steps use checkbox (`- [ ]`) syntax.

**Goal:** Three small phone fixes for the Today screen, approved from a before/after preview (no spec): the year grid opens on the current month, the compound effect card becomes one compact row, and the guest notice fits one line on a phone.

**Architecture:** Three independent component edits, each with its test first. No data, routes or server code change.

**Tech Stack:** React 19, Tailwind v4, Vitest + Testing Library.

**Issue:** #99

## Global Constraints

- Phone width is 390 px; the page must never scroll sideways (the year grid scrolls inside its card).
- Copy on desktop does not change: the guest notice keeps its full text from `md` up, and the compound card keeps its words.
- Never run `next build` in the repo; do not kill processes on the user's machine.
- Run only the tests of the touched files, plus `tsc` and `eslint` (the user asked for fewer full runs; the CI runs the rest).
- Commits: detailed messages ending `Refs #99`, on `feature/99-celular`; no push without the user's go-ahead.

## Review Focus

1. Other years start at January, not at today: moving the year back must not leave the grid scrolled to the right — test in Task 1.
2. The page does not scroll sideways at 390 px with the new layouts — manual check in Task 4.
3. Screen readers on a phone hear one version of the guest notice, not both — the long text is `hidden` below `md` and the short one `md:hidden` (Task 3).
